# Voice Command Recognizer

Recognize simple spoken commands.

## How to run

No installation is required.

1. Extract the ZIP file.
2. Double-click `index.html` to open it in Chrome, Edge, or Firefox.
3. Enter your input and click the button.

## Microphone
Allow microphone access when your browser asks. Use Chrome or Edge for best speech recognition support.

## GitHub upload

Create a separate GitHub repository for this project and upload all files from this folder.
